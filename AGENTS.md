# Repository instructions for AI agents

Before working with EoS-TrENsMUTher, read
[`AIutils/README.md`](AIutils/README.md) and the task-specific resources it
selects. Enumerate `AIutils/` rather than relying on a remembered file list.

The user's request is authoritative. Do not infer undocumented scientific
metadata, change numerical semantics to make a case pass, launch expensive
work, submit external jobs, overwrite results, or perform remote operations
without the corresponding user intent or authorization.

Use current source code, public documentation under `docs/`, and templates
under `templates/` as the software contract. If an AI resource conflicts with
them, report the conflict instead of guessing.
